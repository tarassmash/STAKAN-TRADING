# Щукин · хедж на одной монете · 24/7 на Railway

Торгует **сервер** круглосуточно, страницу можно закрыть.

## Стратегия
- Раз в минуту скан: выбирается **одна самая волатильная монета** (крупные минутные свечи, узкий спред, оборот от N млн $). Монета меняется, только когда по ней нет открытых позиций.
- На монете включается **режим ХЕДЖ** Bybit: лонг и шорт живут одновременно и независимо.
- **Лонг-сторона**: BUY-лимитка ниже цены → исполнилась → тейк SELL-лимиткой на +«тейк» % → закрылась → снова BUY.
- **Шорт-сторона**: SELL-лимитка выше цены → исполнилась → тейк BUY-лимиткой на −«тейк» % → закрылась → снова SELL.
- **Хедж всегда в балансе**: вторая сторона входит ровно на такой же объём (монет), меньшая сторона доливается до большей. Залог на сторону не больше 45 % депозита — обе стороны всегда помещаются в маржу.
- Куда бы цена ни пошла, одна сторона собирает тейки; вторая ждёт возврата цены.
- **Маркета нет**: все ордера PostOnly-лимитки (мейкер, комиссия 0.02 %).
- **Выход только в плюс**, стопа нет. Позиция висит дольше «мин. плюс через» — тейк опускается до входа + комиссии (+0.05 %).
- 📉 Фильтр OI (опция), ⚡ турбо (ближе вход, короче тейк), 📒 журнал по дням.

## Railway → Variables
`BYBIT_API_KEY`, `BYBIT_API_SECRET`, `UI_PASSWORD`. Volume на `/data`.

## Риск
Стопа нет. На сильном тренде сторона против тренда висит в минусе, пока цена не вернётся, и держит маржу. При плече ×10 движение против ~9–10 % = ликвидация этой стороны. Меньше плечо — дальше ликвидация.
