# Щукин · хедж на одной монете · 24/7 на Railway

Торгует **сервер** круглосуточно, страницу можно закрыть.

## Стратегия
- Раз в минуту скан: **одна самая волатильная монета** (крупные минутные свечи, узкий спред). Меняется, только когда по ней нет позиций. Режим **ХЕДЖ** Bybit.
- **Вход**: BUY-лимитка ниже цены и SELL-лимитка выше. Какая исполнилась первой — **первая позиция**, вторая лимитка снимается.
- Первая в плюс — **тейк** лимиткой +«тейк» % (после «мин. плюс через» — минимальный плюс).
- Первая ушла в минус на «хедж при минусе» % — включается **хедж в обратную сторону ×2 объёма** («хедж × объём первой»), по лучшей цене стакана.
- Пока хедж открыт, первая сама не выходит. **Половина хеджа** берёт тейк +«тейк» % → в **банк цикла**; **вторая половина бежит за трендом** и закрывается на откате от пика на «трейлинг бегуна» %.
- **Разгрузка первой**: как только банк покрывает минус части первой позиции, эта часть закрывается лимиткой — первая уменьшается, риск разворота меньше.
- **Хедж никогда не отдаёт взятое**: был в плюсе ≥ тейк/2, а цена пошла обратно к его входу — хедж закрывается с минимальным плюсом (банк сохраняется). Висит дольше «мин. плюс через» — тоже минимальный плюс. Новый хедж после такого выхода — через 60 с или когда цена ушла дальше прошлого хеджа.
- **Первая + хедж + банк в плюсе (с комиссиями) → закрываю обе** лимитками.
- Без хеджа первая выходит там, где её минус уже покрыт банком.
- Размер первой позиции такой, чтобы она и хедж ×2 точно влезли в маржу; если всё же не влезает — плечо монеты поднимается ровно настолько, насколько нужно.
- Все ордера — **PostOnly-лимитки**, маркета нет. **Стопа нет**, выход только в плюс по циклу.

## Railway → Variables
`BYBIT_API_KEY`, `BYBIT_API_SECRET`, `UI_PASSWORD`. Volume на `/data`.

## Риск
Стопа нет. Если хедж ×2 открылся, а цена развернулась обратно, хедж уходит в минус вдвое быстрее, чем плюсует первая — цикл ждёт, пока цена снова пойдёт в сторону хеджа. Плечо, поднятое ради хеджа, приближает ликвидацию.
